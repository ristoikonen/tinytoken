Command-line reference

TinyToken provides a command-line interface for creating, inspecting and verifying compact, cryptographically attested image and document tokens.

tinytoken

Create a TinyToken from an image or document, or inspect an existing .token file.

Syntax
tinytoken <file> [options]

Arguments

<file>
Source file path (image, document, or existing .token file). REQUIRED

Options

-o, --out <path>
Custom output .token path. Defaults to <input_dir>/<basename>.token.
-v, --verify
Explicitly run and print decode and cryptographic signature audit.
--info
Verbose breakdown: token size, uncompressed estimate, dates and all fields.
--filetype
Print preview filetype (e.g. WEBP, PNG, JPEG, AVIF).
--preview
Stream raw binary preview data to stdout (for saving or piping).
--json
Print token metadata, attestation and Merkle proof as JSON to stdout.
-h, --help
Display this help message.

Examples

Inspect an existing token using the available inspection options.

Inspect token information 
# Inspect an existing token
tinytoken tok_00004_Henri.jpg.token --info
Detect preview filetype 
tinytoken tok_00004_Henri.jpg.token --filetype
Extract preview 
tinytoken tok_00004_Henri.jpg.token --preview > preview.webp
Verify token integrity 
tinytoken tok_00004_Henri.jpg.token -v

Create a token

Create tokens from images or documents. Specify a custom output location when required.

Tokenize an image 
# Create a token from an image
bun tinytoken ./images/Henri.jpg
Tokenize a document 
# Create a token with a custom output path
bun tinytoken ./documents/report.pdf -o ./output/report.token --info
